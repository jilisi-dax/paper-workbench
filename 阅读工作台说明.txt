论文工作台
===========

双击「论文阅读.html」即可使用。建议使用 Edge 或 Chrome。工作台使用本地 PDF.js 加载、绘制 PDF，打开和阅读均可离线进行。

目录结构
--------

• 工程包括「论文阅读.html」「阅读器/」「temp/同步论文目录.ps1」和「catalog.example.json」。
• 「data/」保存本地文献目录、分类、论文、书籍报告和笔记备份。编辑入口为「data/catalog.json」。
• 「cache/」保存生成的浏览器目录和 PDF 离线缓存。首次同步会根据「catalog.example.json」创建空资料库。
• Git 按根目录的「.gitignore」白名单收录工程文件。迁移个人资料时可单独复制「data/」，再同步生成缓存。

阅读与笔记
----------

• 文献库可按标题、分类、团队、标签或文件名搜索。文献列表显示发表时间、入库时间和团队。有 arXiv 记录的论文，发表时间采用首次提交日期。
• 文献列表上方可以按发表时间、入库时间或影响力切换升序和降序，默认按发表时间降序。排序作用于当前分类和搜索结果，也用于阅读导航。缺少对应数据的论文排在最后。浏览器会记住上次选择。
• 影响力采用 OpenAlex 被引次数。点击论文详情里的被引次数可看来源，悬停可看核对日期。网页读取本地保存的数值，可离线排序。
• 点击文献详情或阅读侧栏的「内容简介」，会在左侧打开详细内容介绍。阅读介绍时可以滚动，点击窗外、关闭按钮或按 Esc 收起。窄屏下，弹窗会保持在屏幕内。
• 阅读页从窗口顶部显示 PDF。左栏保留分类和论文简称。点击左上角「论文工作台」可返回首页。点击「文献导航」临时展开完整列表，点其他区域或按 Esc 收起。
• 右栏「阅读」可切换版本、跳页、缩放和单独打开原 PDF。「中英对照」左侧显示中文译本，右侧显示英文原文，两边可分别滚动和跳页。「章节」可定位到选定版本的页码。
• 原位排版的中文译本沿用英文 PDF 页序，可用「中英对照」在同一页码查看两个版本。
• 打开右栏「笔记」即可在底部直接写文字、粘贴截图或添加图片。点击「发送」或按 Ctrl+Enter 记录。普通 Enter 换行。
• 论文笔记默认记录当前版本和该版本的可见页码。通过「标记页码」可选另一版本或手填页码。选择「未指定版本」并留空页码可只记录论文。
• 点左下角「随想录」打开聊天浮窗。在浮窗内发送独立图文，在论文右侧「笔记」发送关联该论文的图文，两者都会出现在浮窗的消息记录中。
• 拖浮窗标题栏可以移动，拖任意边或角可以调整大小。浏览器记住位置、尺寸和打开状态。用浮窗右上角的关闭按钮关闭。
• 论文消息带「论文 · 简称」标签。悬停显示标题、团队、日期、版本和页码。点击标签会在新窗口打开原 PDF，优先定位到笔记页。
• 「全部笔记」可跨论文和随想录搜索。切换论文时，本次打开网页期间的未发送草稿会随会话保留。

保存与迁移
----------

点击「发送」把图文写入当前浏览器的本地存储。换浏览器、移动资料目录或清除浏览器数据前，可以用「笔记备份」保存一份 JSON。在阅读页，备份入口位于右栏底部。

• 「保存到资料目录」弹出文件夹选择后，选包含「论文阅读.html」的「论文资料」目录。工作台会读入并合并现有笔记，再写入「data/笔记/阅读笔记.json」。
• 也可以「下载备份 JSON」，手动存放到「data/笔记」目录。备份包含图片，导入同一文件即可恢复图文。
• 「导入笔记 JSON」按记录 ID 合并，同一 ID 保留修改时间较新的记录。备份也会记录删除，用于避免导入旧备份时恢复已删除条目。

给后续 Agent 的维护约定
-----------------------

「data/论文/」外层是收件区，用于暂放用户新粘贴的 PDF。已入库的每份 PDF 保存两份。
• 原件存入「data/论文/原始pdf/」，保留收到时的文件名和内容。
• 阅读副本存入「data/论文/分类名/」，分类目录名与网页 categories.label 一致。副本用网页上对应语言的标题命名，工作台从这里打开 PDF。

1. 扫描「data/论文/」外层的新 PDF。先计算 SHA-256 并与归档原件比对。内容完全相同的 PDF 只保留已有的一份原件和一份分类副本。确认两份保留文件齐全且哈希一致后，删除收件区或旧重复目录中同哈希的冗余文件。
2. 根据封面、书签和论文页面核实标题、语言、署名、日期、版本与页码。用 arXiv ID、DOI 或标题和作者判断是否属于已有论文。内容不同的修订版和译本应分别保留，加入同一篇论文的 versions。
3. 原件按收到时的文件名归档。原名相同但内容不同的 PDF，放到「data/论文/原始pdf/」下的子目录中区分，文件名保持原样。分类副本用对应语言的完整标题命名。Windows 保留字符用对应全角字符替代，例如英文标题中的冒号用「：」。同一篇同一语言有多个修订版时，在标题后加「 [v1]」「 [v2]」等版本标识。
4. 更新「data/catalog.json」。versions[].sourceFile 记录保留原名的归档路径，versions[].file 记录分类副本路径，两者均为相对于「data/」、以「论文/」开头且使用正斜杠的路径。新论文填写首次入库时间 addedAt。补入译本、修订版或更新元数据时，保留原入库时间和论文、版本 ID，以维持排序、笔记和阅读定位的关联。
5. 在「论文资料」目录运行下面的同步命令。刷新网页，检查论文、分类、章节和 PDF 的打开路径。验证完成后，清理已处理的收件区 PDF。

    powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File ".\temp\同步论文目录.ps1"

脚本检查论文 ID、分类、PDF 路径和章节页码。填写 sourceFile 时还会核验原件与分类副本的 SHA-256 一致。脚本更新「cache/catalog.js」，并在「cache/pdf-data/」生成按文件内容索引的离线缓存。未变更的 PDF 会复用现有缓存。原件齐全时可以重新生成离线缓存。以 JSON 为编辑源。

目录的顶层有 schemaVersion（当前为 1）、categories 和 papers。
分类由 categories 数组配置，按数组里的顺序显示在首页和阅读导航。每项填写 id 和 label，shortLabel 是可选的窄栏简称。例如 {"id": "sample-category", "label": "示例分类", "shortLabel": "示例"}。新增、调整顺序或修改简称时，编辑 JSON 后同步目录即可。分类改名涉及分类文件夹时，一并更新相应的 PDF 路径。

papers 每项是一篇论文，category 填对应分类的 id。下面是单条记录的例子，入库时填写实际文件名和页码。

    {
      "id": "example-paper",
      "category": "sample-category",
      "shortTitle": "",
      "published": "",
      "addedAt": "2026-11-21T16:39:00+08:00",
      "team": "",
      "title": {"zh": "", "en": "Example Paper Title"},
      "description": {"zh": "", "en": ""},
      "overview": [{"title": "问题与背景", "text": "介绍论文研究的问题、方法和证据。"}],
      "tags": [],
      "versions": [
        {
          "id": "en",
          "language": "en",
          "revision": "",
          "file": "论文/示例分类/Example Paper Title.pdf",
          "sourceFile": "论文/原始pdf/2025.12345v1.pdf",
          "pages": 10,
          "toc": [{"title": "Introduction", "page": 2, "level": 1}]
        }
      ]
    }

• paper.id 在整套资料中唯一，version.id 在所属论文中唯一。笔记按这两个 ID 关联，补写内容或改名时保留 ID。
• 标题、简称、日期、团队、简介、标签和章节可留空。shortTitle 留空时，窄栏显示标题开头的一小段。published 用 YYYY-MM-DD 或已核实的年份，team 填论文署名的团队或机构。标题为空时页面会显示另一语言标题或 PDF 文件名。category 留空会归入「未分类」。
• addedAt 使用带时区的 ISO 8601 时间，例如 2026-11-21T16:39:00+08:00。网页按北京时间显示。
• impact 可省略。查询 OpenAlex 后可填写 {"citationCount": 37, "openAlexId": "W4412945681", "checkedOn": "2026-11-21"}。用 DOI、arXiv ID、标题和作者核对同一篇论文。存在单独的正式版和预印本记录时，采用已核实的正式版记录，避免重复计算；已合并的用同一条记录。确认未被引用可填 0，暂未查到时省略。OpenAlex 指标说明 https://help.openalex.org/data/works/citations/
• description 是列表旁的简要介绍。overview 是点击简介后显示的详细介绍，按小节填写，每项包含 title 和 text，建议分别说明问题背景、方法与实验、阅读重点或适用条件。
• 生成中文译稿时使用独立版本 ID 和相应中文标题，将首次导出的 PDF 以原文件名存入「data/论文/原始pdf/」，并在分类目录保存阅读副本。translatedFrom 记录对应英文版 ID。原位译本使用 pageLayout: "source"，按英文 PDF 的实际页序编制章节与定位信息。附原文的旧译本可用 legacyPageMap 按旧页序保存对应的英文页码，工作台会据此定位原有笔记和阅读链接。
• 每份 PDF 使用自己的 toc。page 从 1 开始，按 PDF 实际页序填写。level 从 1 开始，代表章节层级。知道总页数时可填 pages，暂时缺 PDF 时使用 "versions": []。
• 笔记数据与目录分开。备份顶层为 {"schemaVersion": 1, "notes": [...]}。每条笔记包含 id、paperId、versionId、page、pageLayout（可选）、title、body、images、createdAt、updatedAt。paperId 为 null 表示随想录。images 的每项包含 name 和 data（图片的 Data URL）。删除记录保留 id、paperId、updatedAt 和 deleted: true。
